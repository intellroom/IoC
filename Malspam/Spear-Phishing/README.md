# Spear-phishing suplantando a NordVPN

**TLP:CLEAR** · **Fuentes:** blog de NordVPN, Didier Stevens, VirusTotal, Malpedia (RedLine Stealer)

Spear-phishing que suplanta a un empleado de NordVPN ofreciendo "material promocional" — el enlace de Dropbox entrega un RAR cuyo contenido resulta ser **RedLine Stealer**. Dominio (`nordvpn-media[.]com`), correo del remitente falso, URL del archivo y hash SHA1 del PDF señuelo.
