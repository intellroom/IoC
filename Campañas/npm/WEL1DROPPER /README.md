# WEL1DROPPER / Flooding Dropper

**Fecha:** 11-08-2026 · **TLP:CLEAR** · **Fuente:** investigación propia de Intellroom (marcado `@INTELLROOM` en el archivo)

Infraestructura de un dropper distribuido vía **paquetes npm** ("Flooding Dropper"): 13 dominios de distribución, incluidos **Cloudflare Workers usados como proxy/OOB** (`*.workers.dev`) y un dominio propio (`wel1.ru`) con varios subdominios de descarga (`sdk.`, `ext.`, `pkg.`, `net.`), más hashes SHA-256 de las muestras.
