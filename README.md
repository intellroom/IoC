# This project is for share IoC's to the community from my own investigations.

## Índice

Todas las campañas del repositorio, con enlace directo a su carpeta. Cada carpeta tiene un `README.md` con el resumen y, en las campañas recientes, un `iocs.txt` listo para bloqueo rápido.

### Cómo compartir un enlace

Desde el 23-09-2026 las campañas están en `Campaign/` (antes `Campañas/`). La ruta ya no lleva ñ, así que **el enlace directo a una carpeta o a un `iocs.txt` se puede compartir tal cual**. Los enlaces antiguos a `Campañas/` dejaron de funcionar: busca la campaña en este índice.

Cada campaña tiene además un ancla corta, igual al nombre de su carpeta en minúsculas:

```
https://github.com/intellroom/IoC#macfinger_clickfix_macos
```
